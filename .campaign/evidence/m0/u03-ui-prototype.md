# U-M0-03 UI 原型规格 v0.1（gate 证据）

> 2026-09-21 · 配套交互原型：`.campaign/evidence/m0/u03-ui-prototype.html`（单文件可直接打开，三屏可切换、含弹窗演示）
> 范围：C7 体检入口/报告卡片 + C8 降级因果链/前置确认弹窗（单元定义四件全覆盖）。视觉为线框级原型，不定稿设计系统。

## 1. 屏清单与 SRS 锚点

| 屏 | 内容 | SRS 锚点 |
|---|---|---|
| ① 体检入口 | 发送前主界面「链路体检」按钮；三档（快速/标准/深度）+ 预估耗时与流量；`include_relay_baseline` 默认关（D17）；深度档 + 蜂窝 → 二次确认卡 | C7、FR-9.1、FR-9.11、C10、D17 |
| ② 报告卡片 | 先验 TTL 倒计时；上行/下行/预计耗时/探针流量四宫格；逐路径结果行（推荐/候选/兜底，含 RTT、打洞耗时、实测速率）；瓶颈归属标注；先验作废提示 | C7-②③④、§4.1.9、`diag.path_result`、`diag.completed`、`diag.profile_invalidated` |
| ③ 降级因果链 + 前置确认 | 四步可读因果链（直渲 `degrade.narrative`，UI 不拼文案）；进度条 + 后台回切提示；`below_floor` 前置确认弹窗（预计速率/预计耗时/服务端带宽 ≈2×，三选：继续/取消/严格直连）；`unusable` 报错归因（不静默开始） | C8、FR-10.4（双阈值 5/1 Mbps，NFR-2.13）、FR-10.10、NFR-2.14、`fallback.verdict` |

## 2. 事件 → UI 映射（与 U-M0-02 契约 §4.2 对齐）

| 事件 | UI 反应 | 所在屏 |
|---|---|---|
| `diag.started` | 展示预估流量/耗时；蜂窝必确认（FR-9.11） | ① |
| `diag.layer` | 分层进度（原型以档位说明承载，实现期补层内进度条） | ② |
| `diag.path_result` | 逐条刷新路径结果行 | ② |
| `diag.completed` | 渲染四宫格 + 推荐路径 + 瓶颈归属 | ② |
| `diag.profile_invalidated` | 卡片灰化 + 重新探测提示 | ② |
| `degrade.narrative` | 因果链直渲（steps 顺序渲染） | ③ |
| `fallback.verdict=below_floor` | 前置确认弹窗（继续/取消/严格直连） | ③ |
| `fallback.verdict=unusable` | 报错 + 归因，禁止静默开始 | ③ |
| `path.failback` | 回切直连提示（原型以回切提示文案承载） | ③ |
